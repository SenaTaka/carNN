# 🏎️ carNN Web — ブラウザ完結のAIレーシング（Vercelデプロイ版）

`g_save.py`（Python + matplotlib + numba + multiprocessing）の学習シミュレーションを
**JavaScriptに移植してブラウザ内で完結**させた静的サイトです。
コース作成 → AI学習 → 走行アニメ再生まで、**GPU不要・サーバー不要**で動きます。

> Pythonの学習本体はGUI・長時間実行・並列処理に依存するためVercel（サーバーレス）では動きません。
> こちらは純粋な数値計算だけを切り出してブラウザに載せたもので、Vercelに完全デプロイできます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | コースエディタ + AI学習UI + 走行アニメ表示 |
| `sim.js` | シミュレーション本体（コース・センサー・NN・GA操作）。`g_save.py` のJIT関数を移植。メイン/Worker両用 |
| `worker.js` | 遺伝的アルゴリズムの進化ループ（Web Workerで別スレッド実行。UIが固まらない） |
| `vercel.json` | 静的配信の最小設定 |

パラメータ（センサー角・NN構造266重み・車両諸元・GAの交叉/突然変異/選択）は `g_save.py` と一致させています。

## ローカルで動かす

Web Workerは `file://` では動かないため、HTTPサーバー経由で開いてください。

```bash
cd web
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. クリックでコースのウェイポイントを作成（既存エディタ）
2. サイドバーの「🤖 AI学習」で集団サイズ・世代数を設定
3. 「🚀 学習スタート」→ 下のキャンバスにAIの走行が表示され、世代ごとに賢くなります
4. 「⏹ 停止」で中断

> ⚠️ ブラウザ学習はNumba無しのぶん重いので、まずは集団40・世代60程度から。
> 完走させたい場合は世代数を増やしてください。

## Vercelへデプロイ

### CLI

```bash
cd web
vercel          # プレビュー
vercel --prod   # 本番
```

### ダッシュボード（GitHub連携）

1. Vercelで対象リポジトリをImport
2. **Root Directory** を `web` に設定
3. Framework Preset は **Other**（ビルド設定不要）
4. Deploy

## Python版との関係

- 学習アルゴリズム・車両挙動は同等ですが、乱数や実行順の違いで学習過程は完全一致しません。
- Python版（`../g_save.py`）はそのまま利用可能。重い学習をローカルのマルチコアで回したい場合はそちら、手軽にブラウザで試したい場合はこちら、と使い分けられます。
